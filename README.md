# 🎙️ Meeting Recorder — Talk. Capture. Remember.

A lightweight browser tool to **record meetings, calls, or ideas** straight from your mic.  
Runs fully in your browser — no installs, no accounts, no nonsense.

---

## 🚀 What It Does

- 🔴 **Start / Stop Recording** with a click  
- 💾 **Instant Download** in `.webm` format  
- 🧭 **Privacy-friendly** — everything stays local  
- ⚡ **Fast and distraction-free** interface  

---

## 🧰 Built With

| Part | Tech | Purpose |
|------|------|----------|
| Structure | HTML | Page layout |
| Style | CSS | Simple, centered UI |
| Logic | JavaScript (MediaRecorder API) | Recording + file handling |
| Hosting | GitHub Pages | Always online, always free |
